# آسيا — نظام إدارة المكتب

تطبيق ويب عربي (RTL) يُدير مكتب خدمات ومعاملات من الألف إلى الياء: العملاء، المعاملات، الدفعات، الخزينة، المستندات، الفواتير، والتنبيهات. يعمل على الكمبيوتر والهاتف، ويُثبَّت كتطبيق (PWA).

## ماذا يقدّم التطبيق

**العملاء**
ملف لكل عميل: فرد أو شركة أو كفيل. تتبع الشركةَ موظفوها، ولكل منهم مجلد مستندات خاص. من ملف العميل ترى معاملاته وما عليه من مستحقات ومستنداته وكشف حسابه.

**المعاملات**
- كل معاملة لها رقم تلقائي وعميل وبنود (خدمة وسعرها) وتاريخ يمكن تحديده، وموظف مسؤول وموعد تسليم.
- تُفصل الرسوم الحكومية (يدفعها المكتب عن العميل) عن أتعاب المكتب (الربح)، مع دعم الخصم.
- مراحلها: جديدة، قيد الإجراء، بانتظار مستندات، مكتملة، ملغاة. وحالة الدفع تُحسب تلقائياً من الدفعات.
- لكل معاملة سجل بكل تغيير مع اسم الموظف ووقته.

**الدفعات والمستحقات**
تسجيل الدفعات بطرق متعددة (كاش، بطاقة، تحويل، شيك) مع رقم المرجع واسم المحوِّل وصورة الإيصال، وإمكانية التعديل مع بقاء السجل. لا تُقبل دفعة أكبر من المتبقي.

**الخزينة**
حسابات (صندوق، بنوك) تُحسب أرصدتها من دفتر حركات فقط، فلا تلاعب بالأرقام. مصاريف وتحويلات داخلية وجرد للصندوق يسجل الفرق، وكشف حساب برصيد جارٍ.

**المستندات**
مكتبة تُعرض كمجلدات (أفراد، شركات، كفلاء) بنفس ترتيب أرشيفك، برفع متعدد أو بالكاميرا أو رفع مجلد كامل. معاينة PDF وصور، نقل وتعديل وحذف، ومشاركة عبر رابط مؤقت برمز سري.

**التنبيهات والتذكيرات**
- تنبيهات تلقائية قبل انتهاء المستندات (الرخص، الإقامات، الجوازات...) بفترات قابلة للضبط لكل نوع، مع إشعارات على الهاتف لصاحب العمل.
- تذكيرات حرة يكتبها المستخدم بأي نص وتاريخ، دون ربطها بمستند.

**الفواتير وعروض الأسعار**
فاتورة وعرض سعر بتصميم المكتب (شعار وختم وبيانات بنكية) بالعربية أو الإنجليزية أو بهما، وطباعة أو حفظ PDF. يتحول عرض السعر الموافَق عليه إلى معاملة بضغطة واحدة. وكتالوج خدمات بأسعار جاهزة.

**التقارير**
الوارد والرسوم الحكومية والمصاريف وصافي الكاش، أداء الموظفين، أعلى العملاء، أعمار الديون، مع تصدير Excel.

**البحث الذكي**
بالكتابة أو بالصوت بالعربية: يفهم الأسماء والحالات والمبالغ ويجيب عن أسئلة مثل «رصيد الكاش» و«عملاء عليهم مستحقات».

**المستخدمون والصلاحيات**
مالك وموظفون بمسميات حرة وصلاحيات تُمنح واحدة واحدة، تُفرض في قاعدة البيانات نفسها لا في الواجهة فقط. يدخل الموظفون برابط المكتب ورمز قصير بلا بريد. سجل نشاط كامل، وسلة محذوفات تتيح الاسترجاع.

## التقنيات
Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · PostgreSQL (Supabase أو Railway) · تخزين متوافق مع S3 (Cloudflare R2) · Web Push.

## التشغيل

**تجربة بلا حساب** (قاعدة محلية وبيانات وهمية):
```powershell
npm install
npm run demo
```
ثم افتح `http://localhost:3000`. و`npm run demo:reset` يعيد البيانات الأصلية.

**تشغيل حقيقي:**
```powershell
copy .env.example .env.local   # املأ القيم
npm run dev
```

## المتغيرات

| المتغير | الاستخدام |
|---|---|
| `DATABASE_URL` | قاعدة PostgreSQL (Railway). تُنشأ الجداول وتُطبَّق التحديثات تلقائياً عند كل تشغيل |
| `OWNER_EMAIL` / `OWNER_PASSWORD` / `OWNER_NAME` | حساب المالك في أول تشغيل (احذف كلمة المرور بعده) |
| `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` | بدل `DATABASE_URL` عند استخدام Supabase، وتُشغَّل ملفات `supabase/migrations` بالترتيب |
| `NEXT_PUBLIC_SITE_URL` | العنوان الحقيقي للتطبيق، تُبنى عليه الروابط المشتركة |
| `CRON_SECRET` | يحمي فحص التنبيهات `/api/cron/alerts` ويوقّع رموز المشاركة |
| `S3_ENDPOINT` / `S3_BUCKET` / `S3_ACCESS_KEY_ID` / `S3_SECRET_ACCESS_KEY` / `S3_REGION` | مخزن الملفات. مطلوب عند استخدام Railway |
| `GEMINI_API_KEY` | اختياري: قراءة المستند تلقائياً (النوع والاسم وتاريخي الإصدار والانتهاء) بمفتاح مجاني من aistudio.google.com، ويختار التطبيق أحدث نموذج متاح بنفسه. بدونه تُستخدم قراءة محلية أقل دقة |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | الإشعارات (`npm run vapid` يولّدها) |

عند استخدام Cloudflare R2 أضف قاعدة CORS للـ Bucket تسمح بـ `PUT` من عنوان التطبيق.

## النشر على Railway
1. ارفع المشروع إلى GitHub ثم New Project > Deploy from GitHub، وأضف **PostgreSQL** من New > Database.
2. أضف المتغيرات أعلاه، و`DATABASE_URL` = `${{Postgres.DATABASE_URL}}`.
3. الأمران الافتراضيان يكفيان (`npm run build` ثم `npm run start`). ويعمل فحص التنبيهات اليومي داخل التطبيق نفسه.
4. بعد النشر: الإعدادات > إشعاراتي > فعّل الإشعارات (على الآيفون ثبّت التطبيق أولاً).

## الأمان
- الملفات في Bucket خاص، ولا تُفتح إلا بروابط موقّعة قصيرة العمر.
- الأرصدة والتقارير محمية بسياسات RLS حسب الصلاحية.
- روابط المشاركة تُخزَّن مجزّأة (SHA-256) وتُقفل بعد 5 محاولات خاطئة، وكذلك رموز دخول الموظفين (15 دقيقة).
- الحذف ينقل إلى سلة المحذوفات ولا يمحو شيئاً، وكل تغيير حساس يُسجَّل في سجل النشاط.
- أخطاء الخادم والمتصفح تظهر في سجلات Railway بوسم `[action-error]` و`[client-error]`، وفي الإعدادات فحص لإعدادات التخزين.

## بنية المشروع
```
src/app/          الصفحات (app) للمستخدمين، و(auth) للدخول، وروابط المشاركة والطباعة
src/components/   مكونات الواجهة المشتركة
src/modules/      منطق الخادم (Server Actions) لكل وحدة
src/lib/          الصلاحيات، الاتصال بالقاعدة، التخزين، أدوات مساعدة
supabase/migrations/   ملفات قاعدة البيانات بالترتيب
scripts/          تهيئة القاعدة والوضع التجريبي
```
